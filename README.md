# Fitness-Tracking-Microservices

**Java Spring Boot AI Full Stack Microservices Course: Building Fitness Application**

Designed and developed a microservices-based backend for a fitness tracking application by splitting functionalities into independent services.

Implemented separate services for user management and activity tracking to improve modularity and scalability.

Built RESTful APIs using Spring Boot to handle user data, workout logs, and progress tracking.

Integrated MySQL database using JPA/Hibernate for efficient data persistence.

Enabled inter-service communication using REST APIs for seamless data flow between services.

Structured the application using layered architecture (Controller-Service-Repository) for maintainability.
